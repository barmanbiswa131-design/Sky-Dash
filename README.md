# Sky Dash

An original, offline-first colorful 3-lane endless runner.

## Features
- Original runner character and visual style
- 3 lanes, swipe/keyboard controls
- Jumping, coins, obstacles, score and speed progression
- Pause and game-over screens
- No API keys or network calls required to play
- Designed as a separate project from CINEVA

## Run
Open `index.html` in a modern browser.
