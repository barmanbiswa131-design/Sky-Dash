# Personal AI

A mobile-first personal AI project designed to become a JARVIS-style assistant.

## Core goals
- Listen to the user's voice through Android microphone with permission.
- Understand spoken Bangla/Banglish/English and common misspellings.
- Answer naturally with voice.
- Proactive conversation: speak first when a useful trigger/event is detected.
- Respect commands such as "chup thako" and "abar kotha bolo".
- Stay quiet when told to stay quiet.
- Optional memory, controlled by the user.
- Background operation within Android/Termux permissions and battery limits.
- Start free/local where practical; add cloud services only when needed.

## Build approach
1. Termux prototype
2. Voice input/output
3. Conversation brain
4. Proactive event detection
5. Memory and personality
6. Android background service
7. Android app packaging

This repository is intentionally starting clean.
